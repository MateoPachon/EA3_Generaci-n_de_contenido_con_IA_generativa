# EA3_Generaci-n_de_contenido_con_IA_generativa
Este repositorio contiene el notebook de Google Colab para la experimentación de Fine-Tuning de un Modelo de LLM en español, con el objetivo de automatizar la redacción de copywriting para e-commerce.


## Guía de Usuario - Aplicación Gradio

Esta guía explica cómo interactuar con el modelo de generación de texto a través del enlace público de Gradio.

Requisitos:
El notebook de Colab debe estar activo y en ejecución para mantener el enlace público de Gradio funcional.

Pasos de Uso:
1. Acceder a la Aplicación: Abre el enlace público generado en la última celda del notebook.
2. Definir la Entrada: En el cuadro de texto etiquetado como "Ej: Zapatos deportivos para correr", introduce el nombre o una frase clave del producto que deseas describir.
3. Generar Contenido: Haz clic en el botón "Submit".
4. Analizar el Resultado: El texto generado aparecerá en el cuadro de "Descripción de Producto Generada". Evalúa la coherencia, el tono y la adecuación del copywriting antes de usarlo.
